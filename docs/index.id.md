# Marien Docs

Tampilkan konten di layar dalam empat langkah.

1. [Siapkan perangkat](setting-up-your-device.md): pasang Marien Player di layar.
2. [Hubungkan layar](connecting-a-screen.md): masukkan kode dari layar ke Marien CMS.
3. [Buat playlist](creating-a-playlist.md): isi tayangan yang akan diputar layar. Mau menggabungkan gambar, video, teks, dan lainnya dalam satu tampilan? [Rancang scene](designing-a-scene.md).
4. [Buat campaign](creating-a-campaign.md): tayangkan playlist itu di layar.

## Mengelola layar sehari-hari

- [Live Control](live-control.md): tampilkan sebuah scene di layar saat itu juga, seperti remote.
- [Tambah sub-account](adding-a-sub-account.md): beri rekan timmu login sendiri untuk layar yang kamu pilih.
- [Cara kerja review](how-reviews-work.md): setujui dulu perubahan dari sub-account sebelum sampai ke layar.

Lainnya: [Versi Player](player-releases.md) · [Device Owner lewat Wi-Fi](remote-device-owner-setup.md)
