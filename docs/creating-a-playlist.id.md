# Buat Playlist

Playlist adalah daftar tayangan yang diputar layar secara berulang: gambar, video, situs web, atau scene buatanmu sendiri.

**1.** Di Marien CMS, buka **Playlists** lalu klik **New playlist**. Beri nama, lalu klik **Create**.

![Memberi nama playlist baru](images/playlist/01-new-playlist.png)

**2.** Klik **Add media**, pilih yang ingin ditampilkan (atau klik **Upload** untuk mengunggah file baru), lalu klik **Add**.

![Memilih gambar dari pustaka media](images/playlist/02-add-media.png)

**3.** Atur isinya:

- Geser baris ke atas atau bawah untuk mengubah urutan.
- Klik waktu di sebuah baris (misalnya **10s**) untuk mengubah berapa lama item itu tampil.
- Tanda panah di sebelah **Add media** dipakai untuk menambahkan **Website**, atau **custom scene** yang kamu rancang sendiri di kanvas.

Klik **Save**.

![Playlist berisi tiga item](images/playlist/03-arrange.png)

!!! tip
    Pratinjau di bagian bawah menampilkan playlist dalam bentuk layarmu. Pilih layarmu di menu dropdown-nya.

Berikutnya: [Buat Campaign](creating-a-campaign.md) untuk menayangkannya di layar.
