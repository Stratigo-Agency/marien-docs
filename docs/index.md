# Marien Docs

Get a screen playing in four steps.

1. [Set up your device](setting-up-your-device.md): put Marien Player on the screen.
2. [Connect the screen](connecting-a-screen.md): type its code into Marien CMS.
3. [Create a playlist](creating-a-playlist.md): what the screen plays. [Design a scene](designing-a-scene.md) if you want to mix pictures, videos, text and more on one screen.
4. [Create a campaign](creating-a-campaign.md): put it on the screen.

## Run your screens day to day

- [Live Control](live-control.md): show a scene on a screen right now, like a remote control.
- [Add a sub-account](adding-a-sub-account.md): give a teammate their own login for the screens you choose.
- [How reviews work](how-reviews-work.md): approve a sub-account's changes before they reach the screens.

Also: [Player releases](player-releases.md) · [Device Owner over Wi-Fi](remote-device-owner-setup.md)
